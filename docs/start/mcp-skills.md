# 给 AI 配「装备」：MCP 与技能

> 这篇结束，你会：搞懂 MCP 和「技能」到底是啥、能帮你干啥。不用懂技术，看完你就知道怎么让 AI 从「只会聊天」变成「能上手干一堆事」。

## 先打个比方

刚装好的 AI，本事其实有限：它能跟你聊天、能读你电脑里的文件、能帮你改文件。就这些。

但你肯定想让它干更多——帮你查一下某个平台的数据、帮你把网页上的东西扒下来、帮你连上自己的资料库。这些它本来不会，得给它**配装备**。

MCP 和技能，就是两种装备。给 AI 装上，它能干的事一下子就多了。

## MCP 是啥：给 AI 装「插件」

MCP 你可以理解成**给 AI 装插件**——就像手机装 App，装一个多一个本事。

装上 MCP，AI 就能伸手去连**电脑外面的东西**，比如：

- 连上一个数据库，帮你查数据
- 控制浏览器，帮你打开网页、点按钮、截图
- 连上各种平台和工具，帮你来回搬数据

没装 MCP 之前，AI 被关在「只能聊天+改文件」的小房间里。装上之后，等于给它开了一扇扇门，让它能走出去办事。

## 技能（Skill）是啥：把一套活打包成一句话

技能解决的是另一个问题：**你有些活是反复做的，每次交代一长串，烦**。

比如你每周都要干同一套事：扒一篇文章 → 拎出重点 → 整理成清单 → 存到指定文件夹。每次都要把这四步说一遍，累。

「技能」就是把这一长串**打包**起来，起个名字。下次你只说一个词，AI 就自动把这一整串跑完。

说白了：**技能 = 你常做的一套流程的快捷方式**。说一个词，它自动跑一串。

## 小白怎么理解这俩的关系

一句话记住：

- **MCP** 让 AI **能干更多种**事（连外面的工具）
- **技能** 让 AI **干熟悉的事更快**（一句话跑一串）

俩都是给 AI 加 buff 的，方向不同，可以同时用。

## 怎么开始：先用现成的，别自己造

这是给新手最重要的一句话：**别一上来就想自己做 MCP、自己写技能**。那是后面的事。

现在网上已经有一大堆别人做好的 MCP 和技能，拿来直接用就行。就像你装手机 App——你不会自己写一个 App 再用，你是去应用商店下现成的。

具体怎么装、装哪些好用，**以你用的工具官方文档为准**（Claude Code 和 Codex 官方都有说明）。这篇只帮你把概念搞清楚，让你知道「哦，原来还能这么玩」。

## 装上这些「装备」后，AI 能帮你干啥

给你几个画面，感受一下：

- 你说「看看我那个表里这个月卖了多少」，它直接连数据库给你查出来
- 你说「把这个网页里的联系方式整理成表格」，它打开网页、扒数据、给你列好
- 你说「走一遍我那套整理流程」，它把你常做的四五步一口气跑完

从「跟它聊天」到「派它去办事」——这就是配装备带来的变化。

## 新手最容易卡的地方（也是最该提醒的）

**最大的坑不是技术，是贪。** 很多人一看到 MCP 这么强，就想一口气装十几个、把所有花哨功能都接上，结果装得一团乱、还拖慢速度，最后一个都没用上。

正确姿势：**你眼下真要干哪件事，就装那一个**。用熟了、确实需要了，再加下一个。装一个、用顺一个，比堆一堆吃灰强得多。
