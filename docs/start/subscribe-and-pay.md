# 订阅与付费：到底要花哪些钱、怎么选

::: warning 价格会变，本文只讲「怎么选」
AI 订阅价格调得很勤，本文**故意不写死具体数字**（写了过两天就过时，反而坑你）。具体多少钱，以官方页面当天显示为准。这篇教你的是**怎么判断该买哪个**，这个逻辑不会过时。
:::

> 很多人卡在这一步：「到底要不要花钱？花多少？」——这篇把账给你算明白。

## 一句话总原则

**工具免费装，干活要花钱。** 钱花在「让 AI 给你算力」上，有两种花法：**包月订阅** 或 **按量付费（API）**。

## Claude Code 这边

| 你是谁 | 选哪个 | 为啥 |
|---|---|---|
| 新手 / 轻度用 | **Claude Pro**（包月） | 便宜、够用、不用算账，先上车 |
| 每天重度用 | **Claude Max**（包月·更高额度） | 用得猛，Pro 额度不够时升 |
| 偶尔用 / 想精确控成本 | **API 按量付费** | 用多少扣多少，但要自己充值、看用量 |

> 新手建议：**先开 Pro**。顺手了、发现额度不够用，再升 Max。别一上来就买最贵的。

## Codex（ChatGPT）这边

- 用 Codex 要登录 ChatGPT 账号，**有 ChatGPT Plus 就能用**（重度可看 Pro）。
- 同样支持 API key 按量付费，但对小白麻烦，先用账号订阅那条路。

## 怎么判断「该不该升级 / 该不该花这个钱」

问自己 3 个问题：

1. **我用它一周，省下了多少时间？** 省的时间 × 你的时薪，比订阅费高 → 值。
2. **我是天天用还是偶尔用？** 天天用 → 包月划算；偶尔用 → 按量付费可能更省。
3. **额度够不够用？** 经常提示「额度用完了」→ 该升一档了。

## 省钱小提示

- **先用免费 / 低档试水**，确认这东西真能帮到你，再升级。别为「可能用得上」提前买贵的。
- **一个账号别开太多重复订阅**——想清楚主力用哪个工具。
- 真到了「一个人当一个团队用」的程度，这点订阅费跟它给你创造的价值比，不算啥（但那是后话，先从最小的开始）。
