# 在 VS Code 里用（贴着文件干活）

> 这篇结束，你会：知道 VS Code 是啥、为啥小白也能装、怎么在里面用上 Claude Code 和 Codex，还有什么时候该用编辑器、什么时候用终端。不懂代码也能跟着走。

## 先说清：VS Code 是啥

VS Code（全名 Visual Studio Code）是**全世界最流行的免费代码编辑器**，微软出的，Mac、Windows 都能装。

别被「代码编辑器」吓到。你可以把它就当成一个**能打开各种文件的高级记事本**——左边是文件列表，中间是文件内容，你点开哪个看哪个。小白完全装得来、用得来。

为啥讲它？因为 **Claude Code 和 Codex 都能在 VS Code 里用**。装个插件，AI 就住进你的编辑器，你能一边看文件一边让它帮你改。

## 两个工具都能进 VS Code

- **Claude Code** 可以在 VS Code 里用。
- **Codex** 也可以在 VS Code 里用。

具体是装插件还是别的集成方式，官方时不时会更新，**以官方最新为准**。但思路是一样的：在 VS Code 里把对应的官方插件装上，AI 就能在编辑器里跟你配合干活。

## 怎么找插件

1. 打开 VS Code。
2. 左边那一竖排图标里，找**像四个方块的那个**（扩展市场 / Extensions），点开。
3. 上面有个搜索框，**搜「Claude Code」或「Codex」**，找带「官方」标识的那个装上。

> 插件的确切名字、安装步骤可能随版本变，**请在 VS Code 扩展市场里搜 Claude Code / Codex 官方插件，以官方最新为准**。装哪个看你想用哪个工具，想都用就都装。

## 在编辑器里用 AI 好在哪

最大的好处一句话：**你能亲眼看到它改了哪儿。**

- **改动看得见**：它动了哪个文件、改了哪几行，编辑器里清清楚楚，不会糊里糊涂。
- **适合局部小修改**：比如就改这一段、调一个小地方，贴着文件指给它看，特别顺手。
- **适合「解释这段是啥」**：看不懂某段内容，选中它，让 AI 给你讲讲，像有个人在旁边坐着教你。

## 什么时候用 VS Code，什么时候用终端

两个入口不冲突，看你干啥活挑着用：

- **用 VS Code（编辑器）**：你想**盯着文件**改、做局部小修小补、让它解释某段内容、喜欢看得见摸得着的——用编辑器舒服。
- **用终端 CLI**：你想让它**放开手大干**，一口气读一堆文件、跑整套任务、自由度拉满——用命令行更强（怎么装命令行版看 [CLI 安装与登录](/start/cli-login.html)）。

新手建议：先用顺一个，别一上来两个都开。想盯着文件就从 VS Code 起步，想体验最强能力就从终端起步。

## 不懂代码也能用：把它当「带 AI 的记事本」

就算你一行代码都不会，VS Code 照样有用。

把它想成一个**装了 AI 的记事本**：你打开任何文件（笔记、文案、表格都行），让住进来的 AI 帮你读、帮你改、帮你解释。你负责说人话提需求，它负责动手。代码不代码的，不影响你用。

## 新手最容易卡的地方（我当年都栽过）

1. **找不到扩展市场在哪** → 就是左边那排图标里**四个方块**那个，鼠标放上去会显示 Extensions，点它。
2. **搜出来一堆插件，不知道装哪个** → 认准**带官方标识**的那个。拿不准就回官网核对一下名字，以官方最新为准。
3. **装完没反应** → 很多插件装完要**把 VS Code 关掉重开**才生效，先重启一下再看。
4. **以为必须先会编程** → 不用。VS Code 只是个壳，真正干活的是住进去的 AI，你说需求就行。
