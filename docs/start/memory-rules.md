# 写你的第一份「规矩」：CLAUDE.md / AGENTS.md

> 这篇结束，你会：给 AI 立一份「说明书」，让它每次干活前自己看一遍。从此不用每次重复交代——它越用越懂你。

## 先说人话：这俩文件是干啥的

你跟 AI 聊久了会发现一个烦人的事：每次都得重新交代一遍——「请说中文」「别动我那个文件」「不确定就先问我」。聊到第三天，嘴都说累了。

`CLAUDE.md` 和 `AGENTS.md` 就是来解决这个的。它俩是给 AI 立规矩的**说明书**：你把要求写一次，AI 每次干活前自己翻一遍，照着办。

- **Claude Code** 自动读 `CLAUDE.md`
- **Codex** 自动读 `AGENTS.md`

内容写法一模一样，区别只是文件名不同。两个工具都用的话，就两份都写（内容基本能照抄）。

## 放哪儿？放你的项目文件夹里

什么叫「项目文件夹」？就是你让 AI 帮你干活的那个文件夹。比如你在桌面建了个文件夹叫 `我的网站`，让 AI 在里面忙活，那这份说明书就放进 `我的网站` 里。

AI 在哪个文件夹干活，就读哪个文件夹里的说明书。放对地方，它才看得见。

## 里面到底写什么

不用写得多高级，就写四类东西：

1. **你的偏好**——比如「请用中文回答」「别啰嗦，直接说结论」
2. **禁区**——比如「别动 `config` 那个文件夹里的东西」「改之前先问我」
3. **项目背景**——比如「这是我开的一个小淘宝店的素材整理文件夹」
4. **常用做法**——比如「整理文件就按月份分文件夹」

说白了，就是把你脑子里那些「我希望它这么干」的念头，写下来给它看。

## 为啥这一步这么重要

不写说明书，AI 就像每天来上班都失忆的新员工——你得从头教一遍。写了说明书，它就成了**记得住事的老员工**：

- 不用你每次重复交代，省嘴
- 上次说过的偏好，这次自动遵守
- 同一个错少犯第二遍

这就是从「会用 AI」迈到「**调教出一个懂你的 AI**」的关键一步。

## 直接照抄改：一份超简单模板

新手别想太多，先复制下面这几行，存成 `CLAUDE.md`（用 Codex 就存成 `AGENTS.md`），放进你的项目文件夹。然后按自己情况改两句就行：

```markdown
# 给 AI 的规矩

- 请永远用中文回答我。
- 别啰嗦，先说结论，再说细节。
- 改任何文件之前，先告诉我你打算改啥，等我点头再动手。
- 不确定的地方，宁可问我，也别自己瞎猜。
- 这个文件夹是我用来整理资料的，里面的原始文件别随便删。
```

就这么简单。五六行，但它能帮你省下后面无数次重复交代。

::: tip 小提示
`.md` 是一种纯文本格式（叫 Markdown），用电脑自带的「文本编辑」/「记事本」就能写，存的时候文件名结尾记得是 `.md`，不是 `.txt`。
:::

## 新手最容易卡的地方（我也踩过）

**第一个坑**：写完没生效。多半是**文件放错地方了**，或者文件名写成了 `claude.md`（小写）、`CLAUDE.txt`（后缀错了）。正确就是 `CLAUDE.md` / `AGENTS.md`，大小写和后缀都要对。

**第二个坑**：一上来就想写得面面俱到，憋了半天一个字没写。别。**先写三行能用的，以后想到再加**——这份说明书是越用越长、慢慢长出来的，不是一次写完的。

**第三个坑**：规矩写得太玄乎，比如「请专业一点」。AI 看不懂「专业」是啥意思。要写**具体**的，比如「回答里别用英文术语」「每段别超过三句话」。
