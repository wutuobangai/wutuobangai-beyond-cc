# 排障手册：卡住了怎么自救

> 这篇结束，你会：碰到最常见的几种「卡住」时，自己就能搞定，不用到处求人。

## 先别慌

AI 出问题，**九成是小事**——不是你电脑坏了，也不是你笨，更不是这工具不行。多半是个小磕绊，重开一下、把话说清楚，就过去了。

下面把新手最常撞上的几种情况，一个一个拆给你看。对号入座就行。

## 1. 输了命令，提示「command not found」（找不到这个命令）

**啥情况**：装是装上了，但你当前这个窗口还没「认」到它。

**怎么自救**：把终端（或 PowerShell）窗口**整个关掉，重新开一个**，再输一遍。八成就好了。这是最常见的小坑，[安装那篇](/start/install-claude-code.html)里也提过。

## 2. 登录失败 / 登录页一直转圈打不开

**啥情况**：基本都是**网络**问题——它要连国外的服务器。

**怎么自救**：

- 先确认你能正常打开对应的官网，能打开说明网络通
- 打不开就换个网试试（比如切手机热点）
- 一直转圈，关掉重新登一次

## 3. 它不听话，乱改东西

**啥情况**：多半是你**没说清**，它自己猜了个方向，猜歪了。

**怎么自救**：

- **把话说具体**：别说「整理一下」，要说「按月份分成子文件夹，原文件别删」
- **给它立规矩**：把你的要求和禁区写进说明书，它每次都会照着办——怎么写看 [写你的第一份「规矩」](/start/memory-rules.html)
- 已经动手跑歪了，直接喊停，告诉它哪儿不对，让它重来

## 4. 它改错了，把文件弄乱了

**啥情况**：它干活时手伸太长，改坏了不该改的。

**怎么自救**：

- 最简单：直接跟它说「**刚才的改动撤回，恢复成原来的样子**」，它一般能帮你改回去
- 平时养成习惯：让它动重要文件前，**自己先把文件复制一份备份**。有备份，天塌不下来
- 这也是为啥要管好它的权限——详见 [跑通你的第一个任务](/start/first-task.html) 里说的「先看它打算干啥，再放手」

## 5. 额度 / 次数用完了，它不干活了

**啥情况**：订阅有用量上限，或者按量付费的余额见底了。

**怎么自救**：看 [订阅与付费](/start/subscribe-and-pay.html) 那篇，搞清你是哪种付费方式、怎么续。等额度恢复或充上，就能接着用。

## 6. 干到一半网突然断了

**啥情况**：它正连着服务器干活，网一抖就断了。

**怎么自救**：

- 检查网络，恢复后重新打开它
- 重要的活，养成**让它边干边把结果存进文件**的习惯，这样断了也不至于全白干

## 7. 它「一本正经地瞎编」（这个最要命）

**啥情况**：AI 有个毛病叫「幻觉」——它会非常自信地告诉你一个**听起来很对、其实是编的**答案。比如编一个不存在的命令、说一个根本没有的功能。

**怎么自救**（重点记住）：

- **越关键的事越要核实**。涉及钱、涉及重要决定的，别它说啥你信啥
- **让它给依据**：「这个说法你从哪看到的？把出处给我」——拿不出依据的，打个问号
- **交叉验证**：拿不准就上官网查一下，或者换个问法再问它一遍，看说法对不对得上

记住一句话：**AI 是个能干的助理，但不是永远正确的权威**。它干活快，但你得当那个把关的人。

## 什么时候该停下来问人

自己捣鼓也有个度。碰到下面这几种，别硬扛，去问人或查官方：

- 同一个错，**试了三四种办法还是不行**——别死磕，省下的时间不值
- 涉及**钱、付款、删重要数据**的操作，心里没底——宁可慢一点，先问清楚
- 看到一堆看不懂的英文报错，越改越乱——**停手**，把报错原样复制下来，拿去问人/查官方，别瞎试

## 一句过来人的话

卡住，**太正常了**。我当年天天卡，一个命令能卡一下午。但有个规律你记住：**卡一次，会一次**。今天卡的这个坑，下次你就绕过去了。所有现在看着很溜的人，都是这么一个坑一个坑爬出来的。

能看到这儿，说明你已经把「零基础上手」这条线走完了——会装、会用、会立规矩、会配装备、卡住了也知道怎么自救。**你已经不是门外汉了。**
