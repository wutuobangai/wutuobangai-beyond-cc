# 跑通你的第一个任务：从「会聊」到「会干活」

> 装好了、登录了，别急着研究高级功能。**第一天就让它帮你干成一件真事**——这一下，你就从「看教程」变成「真会用」了。

## 先选一件「小而真」的活

别一上来挑大工程。挑一个你**手头真实存在、又不复杂**的小事，比如：

- 把一个文件夹里乱七八糟的文件，按日期 / 类型理一理
- 读一篇很长的文章 / 文档，给你拎出重点
- 把一份资料从一种格式整理成另一种（比如乱的笔记 → 整齐的清单）
- 帮你写一段邮件 / 通知 / 朋友圈文案

> 关键是「真」——是你本来就要干的活，不是为了练习硬编的。这样你立马能感受到它到底帮没帮上忙。

## 怎么跟它说（大白话提需求）

打开 Claude Code（终端输 `claude`）或 Codex（输 `codex`），然后**像跟一个聪明助理说话一样**，把这三样说清楚：

1. **要干啥**：「帮我把这个文件夹里的文件按日期归类」
2. **给背景**：「文件在桌面的 XX 文件夹，文件名里带日期」
3. **要什么结果**：「整理成按月份分的子文件夹」

> 不用懂术语、不用写代码。**说人话，把事情交代清楚就行**——它会自己想办法。

## 它会怎么干（这就是和网页 AI 最大的不同）

网页 AI 只会「告诉你怎么做」；Claude Code / Codex 会**自己动手做**：

1. 它先**看现场**（读你的文件夹、看文件长啥样）
2. **告诉你它打算怎么做**（这一步很重要，看一眼对不对）
3. 你点头，它**真的开始动手**
4. 干完**告诉你结果**

## ⚠️ 新手必守的一条：先看它打算干啥，再让它动手

它要动手改东西时，一般会先问你「可以吗」。**别闭眼狂点同意**——先看一眼它打算干啥，对了再放行。这是安全用它的第一课（详见 [权限与安全](/start/permissions-safety.html)）。

## 验收：怎么算「干成了」

- 结果是你要的 → 成了，夸它一句，下一个任务
- 不太对 → **别重开，直接跟它说哪不对**：「不对，我要的是按月份分，不是全堆一起」——它会改。这种「来回调」正是它比网页 AI 强的地方。

## 你刚刚跨过了一道坎

恭喜——你已经从「问 AI」升级到「**指挥 AI 干活**」了。这就是这条路的第一个真正的台阶。
