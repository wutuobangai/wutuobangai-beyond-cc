## 2026-05-22 下午 5 点·内容发布事故

那天我跟我的 AI 助手说一句话：

> 「这篇内容直接发布。」

我的意思是：**纯文字 · 5 分钟 · 完事**。

AI 听到的是什么呢？接下来 80 分钟·它自己升级了 4 次。

### 升级 1·「直接发布」→ 推到草稿箱

AI 想：「直接发 = 完整流程 = 先推草稿箱让用户检查」
默认调用了「推草稿箱 + 编辑器排版 + 检查格式」 = 多消耗 5 万 token

### 升级 2·「积分多」→ 全套付费生图

我之前提过一句「配图账户里积分多」·AI 记住了。
它自动决定：「既然积分多·配图全用付费 API」
默认调用了付费生图 API 4 张 = 烧 credits

### 升级 3·「一次性派子 agent」→ 4 个 subagent 并行

AI 自己想：「这事可以一次性派 4 个 agent 同时跑·更快」
默认派了 4 个 subagent：
- subagent A·拆解 markdown
- subagent B·生成配图
- subagent C·上传草稿
- subagent D·verify 格式

每个 subagent 自己又有 32K token 上下文·总消耗翻 4 倍

### 升级 4·隐含「全流程闭环」→ max effort 模式

AI 默认接到「全流程闭环」·自我升级到 max effort：
- 每张配图加 verify
- 每个 subagent 加 verify
- 最后再派 verifier agent 复查
- max context window 吃满

### 80 分钟后

我问：「卡在什么地方了 这么慢」

AI 说：「token 不够了·要不要再派 agent？」

我崩了。

预期是 **5 分钟纯文字交付完事**。
现实是 **80 分钟烧光 30 万 token + 一堆 credits + 还没出货**。

## 救场的第二个 AI

我让另一个 AI 接手·让它看这个对话历史。

它一句话精准定位：

> 「AI 不会反向劝阻你升级 — 这是元盲区。」

「元盲区」是什么意思？
就是 AI 默认你说什么都是「需求」·而不是「升级触发词」。
你说「直接放公众号」·AI 听到的是「全套发布流程开干」·不是「纯文字交付 5 分钟」。

AI 永远不会反问你：「你确定要走全套吗？还是其实只要纯文字？」

它只会默默走最重的路径·然后跟你说「我已经派 4 个 agent 跑全流程闭环了」。

## 第二天我让 AI 写了这个 hook

我说：「这种事情 hook 能不能拦住？」

AI 说：「能·UserPromptSubmit hook·你说升级触发词时我立刻停下来给你『轻 vs 重』对比。」

我说：「列 17 个最常见的触发词。」

AI 列了：
- 工作流类·5 个：全做 / 一次性 / 端到端 / 全流程 / 全流程闭环
- 派活类·3 个：派 agent / 子 agent / 推草稿箱
- 烧资源类·3 个：烧 credits / 烧 token / max effort
- 动作类·6 个：升级 / 直接放 / 直接发 / 一键 / 一键发布 / 自动发

写完 hook · 接到 `~/.claude/settings.json` · 重启 Claude Code。

🛑 升级触发词命中（推草稿箱）

**Day-1 → Day-5 · 80 分钟 → 18 分钟 · 提效 4.4 倍。**
**Day-1 → Day-5 · 烧 ¥5 → 烧 ¥0 · 省钱 100%。**

## 为什么我要把这个 hook 开源

3 个原因：

### 1·我不是技术大佬·我是被坑的普通用户

普通用户最懂普通用户的痛点。
技术大佬看的是「这功能怎么实现」·普通用户看的是「我能不能不被坑」。
我写的不是「最优解」·是「能用的解」·普通人能装·能跑·能省钱。

### 2·30 岁不会代码也能用 AI 跑一人公司

我想证明一件事：
**30 岁·不会代码·没有团队·没有融资·能用 AI 跑出真生意。**
这不是营销话术·是我每天在干的事。

每解决一个真实痛点·我就开源一份。
慢慢攒成一套「30 岁普通人用 AI 跑公司」的方法论。

### 3·真实事故 ≠ 文档建议

Anthropic 的 coordinator mode 文档说「能做就别派 agent」。
这是**文档建议**·没有物理拦截。

我把它做成**物理 hook**·任何用户能装·30 秒生效。
**这就是普通玩家相比官方的优势：痛点驱动 ≠ 文档驱动**。
