# 一份规矩两个 AI 共用：别养出两套说法

> 作者：阿浩 · 2026-11-18 首写 · 2026-11-26 更新

规矩越写越长，新窗口却还在按旧进度做事。你刚纠正一句，它又往文件里补一句，后来连你自己都不知道该先看哪份。

> 规矩只写一份，两个 AI 从同一个地方读。
>
> 同一件事，我不想给 Claude 讲一遍，再给 Codex 讲一遍。讲两遍，迟早变成两个版本。

用两个 AI 以后，很容易顺手给它们各写一套规矩。开始看着方便，后来一边更新了，另一边还照着旧话做。我再纠正，两边又各加一句，越来越难知道哪句算数。我现在把共同要求放到一个正本里，各自的入口只保留工具和执行方式的差别。

## 真实场景：新窗口到底读了哪版

我的开工 hook 会自动注入同一块共同内容，带上来源更新时间和指纹。hook 可以理解成开工时自动跑的一步，把必需的规矩送进新会话。指纹则是用来核对内容是否相同的标记，不用肉眼逐段找区别。

| 遇到的情况 | 我现在怎么处理 |
|---|---|
| 两边对同一条边界说法不同 | 回共同正本核对，别各补一段 |
| 新窗口说已经知道规矩 | 看实际收到的开工块和来源标记 |
| 注入失败或内容省略 | 明说未知或省略，不能装作读全了 |
| 工具用法只有一边需要 | 留在各自入口，不塞进共同正文 |

## 为什么一份正本还不够

文件统一了，AI 却没读到，行为照样可能分叉。所以我分开看「规矩存在哪」和「这次会话收到什么」。来源时间与指纹给了回查线索，真正有没有读全，还得在新会话入口核。

我也给规矩排层级：老板本人、宪法、法律、条例。这里是我给内部规则起的名字，法律层放固定决定和安全红线，条例层放具体做法。具体手册不能另起一套权限，旧备份也不能冒充今天的正本。

统一不等于把全部资料塞进去。共同正文只讲两边都得遵守的边界，项目资料、岗位经验按任务再读。否则入口越长，越容易截断，真正要用的那句反而到不了眼前。

## 一页固定要求，当前进度另查

只有一份正本，还可能越写越长。今天哪个项目卡住、谁在改哪份文件、上次报错怎样，都塞进去，过几天就变旧。AI 读到的是同一份文件，却仍可能被过期状态带偏。

我后来加了一页固定要求。它只放很少变的东西：谁决定、怎么区分讨论和施工、哪些动作要确认、怎么验收，以及去哪里查当前状态。项目进度和下一步放在另外的记录里。

我们给这一页设了长度约束，提醒自己别继续堆。页数或行数只是本地选择，短也不自动代表好；关键是下一位能不能按入口找到真实资料。新增一条之前，先看是不是重复，或者本来就该放到项目说明。

| 内容 | 放哪 |
|---|---|
| 授权边界、沟通要求、验收底线 | 固定要求 |
| 项目现在怎样、还有谁在做 | 当前状态记录，并回实际文件核 |
| 最近改了什么、怎样退回 | 改动记录 |
| 某个项目怎么启动、怎样检查 | 项目入口 |
| 某次失败的原因和适用条件 | 经验正文，入口只留查找线索 |

复制下面这个骨架，把路径换成你自己的。这里的文件名全是示例：

```text
一页固定要求
我们在做什么：____
谁拍板、冲突时回哪份有效决定核：____
讨论时只分析；明确授权后在范围内做到约定终点。
付款、外发、上线、删除等动作的确认边界：____
怎样算完成、证据放哪、未验怎样说明：____

要查当前情况：看“示例-当前状态.md”，再核实际文件和运行结果。
要查最近改动：看“示例-改动记录.md”。
要查已定条件：看“示例-已定要求.md”。
进入具体项目：先读那个项目的 README。
本页来源／更新时间／内容标记：____
```

状态查不到，就写“没查到”。不能因为固定页指向了状态表，就把表里上周的登记当成今天已经核实。接续中的短进度可以用[最小接续单](/methodology/minimal-resume-note.html)，完成后更新它，别不断追加互相矛盾的状态。

自动注入也要实测。先看工具是否真有这个入口，再查新窗口实际收到哪段；没有注入能力，就按工具支持的方式读取。不要只因另一款工具用了 hook，就假设这里也已经接上。

## 你该怎么做

1. **先定唯一正本。** 明确哪份共同规矩负责授权、交付和沟通；其他入口只指过去，别再复制整篇。
2. **写清层级。** 当轮明确要求、长期规则和具体操作手册分别管什么，发生冲突先回原话及有效规则。
3. **自动带入最小必读。** 两边从同一来源生成开工内容，附来源时间与内容标记；生成结果不再手工各改各的。
4. **核实际接收。** 在各自新会话里查看收到的内容，失败和截断要暴露出来，不能只检查配置写没写。
5. **改一次，再核两边。** 更新正本后检查两个入口，旧版本留作历史，别把历史说明当成当前指令。

> 💡 自检：明天我只改一条共同规矩，两边能不能收到同一句话，并说清它来自哪版？
