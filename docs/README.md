## 痛点驱动，不是文档驱动

不是说我们比 Anthropic 强。是 5 件关键方法论，我们都比官方早落地——每一件都有**时间戳 + 真实事故 + 物理 hook** 可验证。

Anthropic 看百万用户共性，发的是「建议文档」。
我们看一个普通人天天被坑，发的是「装上就能拦的 hook」。

**这就是普通玩家的优势：被真实事故炸，痛了 1 小时就立法。**
