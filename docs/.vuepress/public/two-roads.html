两个场景，一套功夫

网页 AI = 市区自己开；终端 Agent = 有个能自己动手的副驾。开车的底层功夫是同一套，区别只是"怎么跟它说话"。

✈️

私家车，还是飞机

私家车 = 自己用、拉一家人；飞机 = 拉很多人、服务别人。飞机不是私家车的升级版，是你决定要载客了才考的本。

第一条路 · 用网页 AI

不碰一行代码，把 AI 用成每天并肩的搭档。

  1. 门外汉 → 会开口问
  2. 知道哪个工具干哪个活好用
  3. 生图、生视频、做音乐都会玩
  4. 存提示词、给它立规矩，越来越懂你
  5. 花一天写几千字，把"我是谁"喂给它
  6. 不同的事建不同项目，分开管
  7. 常做的事固定成流程，一句话自动跑
一份工作、个人提效——网页对话就够了，不用焦虑。
基础课 · 人人能学
10%
破釜沉舟、要改命的人

第二条路 · 用终端 Agent

让 AI 真动手干活，一个人组装成"一人军团"。

  1. 装上车（Claude Code / Codex）
  2. 安个家（建你和 AI 的"办公室"）
  3. 立规矩（写宪法、写第一个项目）
  4. 换脑子（我当老板，AI 当员工）
  5. 认全员工（各平台、各工具能干啥）
  6. 让 AI 当军师（它出框架，你拍板）
  7. 一人军团（一群 AI 协同，你只做判断）
创业、AI 编程、开公司——这条路很难，想清楚再来。
进阶课 + 陪跑 · 改命的路

⚠️ 注意：用终端 Agent 不比用网页"高级"，它是个平行世界。你在终端里照样要走那一套底层功夫，唯一变的是——从"只对话、复制粘贴"，变成"对话中让它真干活"。所以走第二条路，也得先把第一条练到至少会一半。
